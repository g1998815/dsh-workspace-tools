## 全局约束（Windows 执行时注意）

- **Git for Windows 必须安装且在 PATH**：缺 git 时所有 git 端点返回结构化错误 `git-not-found`（预期行为，不算 bug）。
- **Node.js ≥ 22** 在 PATH（与 Mac 同版本线）。
- **路径语义**：`ctx.fs`/RPC 层 relPath 恒为 POSIX 风格（`/` 分隔）；Windows 侧 `node:path` 自动按 `path.win32` 语义处理，**不硬编码分隔符**（file-tree.js:209 的 `rel.split("/")` 是 POSIX rel，保留）。
- **编码**：git 输出已 `encoding:"utf8"` + `core.quotepath=false`；Windows 控制台代码页不影响 `execFile`（非 shell 解释）。
- **测试基线**：85 全绿（Mac）；Windows 上应同样 85 全绿（除 Task 1 新增）。
- **CRLF 注意**：`parseDiff` 按 `\n` split；git diff 输出在 git 内部统一 LF，untrusted 文件全文视图的 `\r` 在浏览器 `whiteSpace:pre` 下不显示，无需处理（验收时留意，若异常再补 `\r` 剥离）。

### Task 1: 控制台 Windows 显式降级（`unsupported-platform`）

**Files:**
- Modify: `lib/services/console.js`（win32 显式 guard）
- Modify: `test/console.test.js`（+1 用例：win32 → unsupported-platform）
- 无 client 改动（`src/components/console.js` 已有 catch → `panelError` 渲染，已验证结构化错误显示路径）

**Interfaces:**
- Produces: `createShellSession` 在 win32 平台抛 `{ code: "unsupported-platform", message: "Windows 暂不支持控制台" }`（不再依赖 spawnTerminal 的原始抛错）。
- Consumes: `platform()`（`node:os`，已 import）。

- [ ] **Step 1: 写失败测试**

```js
// test/console.test.js 追加
test("createShellSession: win32 throws unsupported-platform (M5)", async () => {
  await assert.rejects(
    createShellSession({ spawnTerminal: async () => { throw new Error("should not be called"); } }, { cwd: "C:\\ws", platform: "win32" }),
    (e) => e.code === "unsupported-platform",
  );
});
```

> 需要给 `createShellSession` 加 `platform` DI 参数（默认 `platform()`），否则无法在非 win32 机器单测。签名改为 `createShellSession(deps, { cwd, rows, cols, platform: plat = platform() } = {})`。

- [ ] **Step 2: 跑测试确认失败**

Run: `node --test test/console.test.js`
Expected: FAIL（无 win32 guard）。

- [ ] **Step 3: 实现**

```js
// lib/services/console.js —— createShellSession 开头加：
export async function createShellSession(deps, { cwd, rows = 80, cols = 24, platform: plat = platform() } = {}) {
  if (plat === "win32") {
    // M5：Windows PTY 后端未实现（spawnTerminal win32 必抛）——显式结构化降级
    throw { code: "unsupported-platform", message: "Windows 暂不支持控制台" };
  }
  // ... 原逻辑不变
}
```

- [ ] **Step 4: 语法 + 全量测试**

Run: `node --check lib/services/console.js && node --test`
Expected: check 通过；86 全绿（85 + 1）。

- [ ] **Step 5: Commit**

```bash

git commit -m "feat: console win32 explicit unsupported-platform guard (M5)"
```
